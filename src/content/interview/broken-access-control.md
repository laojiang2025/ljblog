---
question: 水平越权和垂直越权分别怎么测？
direction: 安全
difficulty: 中级
tags: [安全测试, 权限, OWASP]
---

两者都属于 OWASP 里长期排在首位的失效的访问控制，区别在于越权的方向。

- **水平越权**：同级别的用户之间。A 用户拿到了 B 用户的数据，比如把 `orderId` 改成别人的订单号就能查看。
- **垂直越权**：低权限访问高权限功能。普通员工调用了管理员才有的删除接口。

**测试准备**：至少准备三个账号——同角色的用户 A 和 B、一个高权限管理员。分别抓取三者的合法请求作为基线。

**水平越权怎么测**：

1. 用 A 的登录态，把请求里的资源标识替换成 B 的（URL 路径参数、查询参数、请求体字段、cookie 里的用户标识都要试）。
2. 断言应当返回 403 或 404，且**响应体里不含 B 的任何数据**。只看状态码不够，见过返回 200 但 body 是空壳、以及返回 403 却在错误信息里带出了对方手机号的情况。
3. 别忘了非查询操作：修改、删除、导出、下载附件，这些危害比查询更大。
4. 遍历类接口要验证**返回范围**：列表接口不传或乱传条件时，是否把全表数据都吐出来了。

**垂直越权怎么测**：

1. 用低权限账号直接请求高权限接口。前端不给入口不等于后端有校验——把管理员操作的请求原样重放，只换登录态。
2. 试未授权访问：完全不带 token，或带一个已过期、已登出的 token。
3. 关注仅前端控制的功能：按钮置灰、菜单隐藏都不是防护，必须验证服务端。

**几个容易漏的点**：

- **ID 可枚举**：自增 ID 让越权的成本极低，配合遍历能批量拖库。看到自增 ID 就应提出风险。
- **越权发生在写之后**：有些实现先执行业务再校验权限，虽然最终返回 403，但数据已经被改了。要查库确认。
- **多租户**：SaaS 场景下租户隔离本质也是水平越权，查询必须带租户维度过滤，且过滤条件不能来自客户端传参。
- **批量接口**：单个 ID 校验了，但传数组时只校验了第一个元素。
